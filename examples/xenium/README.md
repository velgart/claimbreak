# examples/xenium

`xenium_to_h5ad.py`: a Xenium output folder (or GEO-style files) to one .h5ad per section.

| script | what it does |
|---|---|
| `xenium_to_h5ad.py` | Raw Xenium output (one .tar.gz per sample) -> one claimbreak-ready .h5ad per sample, a depth survey, and an optional combined file. |
